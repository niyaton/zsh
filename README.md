# Mac Studio 学生アカウント向けZsh設定

研究室・演習室のMac Studioに作成した学生アカウントへ導入するための、小さなZsh設定です。macOS標準のZshだけで動作し、Homebrewや追加プラグインは必須ではありません。

プロンプトにはASCII文字だけを使っています。Powerline FontやNerd Fontをインストールしていないアカウントでも、アイコンが四角形になるなどの文字化けは起きません。

## 含めた設定・含めなかった設定

含めたもの:

- Tab補完と候補選択
- コマンド履歴と前方一致検索
- Gitブランチ名の表示
- 基本的なalias
- `vim`（インストール済みなら`nvim`）を標準エディタにする設定

教員用設定から外したもの:

- Powerline/Nerd Font用アイコン
- Homebrewの固定パスとGNU版`ls`への依存
- tmuxへの自動接続、WezTerm連携
- mise、fzf、Docker、Goなど追加ツール固有の設定
- 教員個人のGitユーザー名・メールアドレス

## 学生アカウントへの導入

学生本人のアカウントでターミナルを開き、このブランチを取得して実行します。

```sh
git clone --branch codex/student-macstudio <このリポジトリのURL> student-zsh
cd student-zsh
sh setup.sh
exec zsh
```

リポジトリを教員アカウントで取得済みの場合でも、`setup.sh`は設定を学生のホームディレクトリへコピーします。そのため、導入後に教員アカウントのリポジトリを読めなくなっても設定は動作します。ただし、スクリプトを実行するときだけは学生アカウントからリポジトリを読める必要があります。

コピー対象は管理している`*.zsh`ファイルだけです。教員環境に残っているコンパイル済み設定（`*.zwc`）や一時ファイルは学生アカウントへ持ち込みません。

既存の`~/.zsh`と`~/.zshrc`がある場合、`setup.sh`は日時と識別番号付きの名前（例: `~/.zshrc.backup-20260901-120000-12345`）へ移してから導入します。元の設定を削除しません。

macOSでは通常、ログインシェルはすでにZshです。確認するには次を実行します。

```sh
echo "$SHELL"
```

`/bin/zsh`以外が表示され、変更が必要な場合だけ次を実行します。

```sh
chsh -s /bin/zsh
```

## Zshの簡単な使い方

基本的なコマンドはBashとほぼ同じです。

```sh
pwd                 # 現在のディレクトリを表示
ls                  # ファイル一覧を表示
ll                  # 隠しファイルを含む詳しい一覧（この設定のalias）
cd ディレクトリ名   # ディレクトリを移動
..                  # 1つ上へ移動（この設定のalias）
mkdir work          # ディレクトリを作成
cp 元ファイル コピー先
mv 元ファイル 移動先
rm ファイル         # ファイルを削除（元に戻せないので注意）
```

便利な操作:

- `Tab`: コマンド名やファイル名を補完します。候補が複数ある場合は、もう一度押すと選べます。
- `Ctrl-P` / `Ctrl-N`: 入力中の文字から始まる過去のコマンドを検索します。
- `Ctrl-A` / `Ctrl-E`: 行の先頭 / 末尾へ移動します。
- `Ctrl-R`: コマンド履歴を後方検索します。文字を入力して絞り込みます。
- `Ctrl-C`: 入力中のコマンドを取り消します。
- `Ctrl-D`: 入力が空ならZshを終了します。
- `cd -`: 直前のディレクトリへ戻ります。
- `dirs -v`: 移動したディレクトリの履歴を表示します。

プロンプトの`[git:ブランチ名]`は、現在のディレクトリがGitリポジトリの場合だけ表示されます。

## 設定ファイル

- `~/.zshrc`: `~/.zsh`内の設定を読み込みます。
- `~/.zsh/01_base.zsh`: 補完、キー操作、エディタを設定します。
- `~/.zsh/alias.zsh`: 基本的なaliasを定義します。
- `~/.zsh/history.zsh`: コマンド履歴を設定します。
- `~/.zsh/prompt.zsh`: 追加フォント不要のプロンプトを設定します。

設定を変更した後は、新しいターミナルを開くか次を実行します。

```sh
source ~/.zshrc
```

## 元の設定へ戻す

導入時に表示されたバックアップ名を確認し、現在の設定を別名へ移してから戻します。以下の`日時`部分は実際の名前に置き換えてください。

```sh
mv ~/.zsh ~/.zsh.student
mv ~/.zshrc ~/.zshrc.student
mv ~/.zsh.backup-日時 ~/.zsh
mv ~/.zshrc.backup-日時 ~/.zshrc
```

もともと`~/.zsh`または`~/.zshrc`が存在しなかった場合は、対応するバックアップの`mv`は不要です。
